ИТОГОВЫЙ ПРОЕКТ: AURA — ПРОСТРАНСТВО ИДЕЙ
===========================================

Состав проекта
--------------
index.html — структура сайта и содержимое разделов.
style.css  — оформление, адаптивная сетка, анимации и состояния элементов.
script.js  — мобильное меню и клиентская проверка формы.
README.txt — эта инструкция.

Как запустить локально
----------------------
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в современном браузере.
3. Для публикации на GitHub Pages загрузите все три файла сайта
   (index.html, style.css, script.js) в корень репозитория.

Что реализовано по требованиям
------------------------------
HTML и семантика:
- HTML5, lang="ru", charset, viewport и meta description.
- Семантические header, nav, main, section, article, form и footer.
- Ссылки-якоря для навигации по разделам.

Современный дизайн:
- Единая цветовая палитра, выразительная типографика и визуальная иерархия.
- Контрастные акценты, аккуратные отступы, карточки и декоративные формы.

Адаптивная верстка:
- CSS Grid и Flexbox.
- Брейкпойнты 900px и 640px.
- Мобильная навигация с раскрывающимся меню.

Анимации и псевдоклассы/псевдоэлементы:
- :hover, :focus-visible, :nth-child, :invalid, ::after.
- transition и анимации @keyframes.
- Учитывается настройка prefers-reduced-motion.

CSS:
- CSS-переменные: --main-color, --accent-color, --background,
  --surface, --muted-color, --font-size и другие.
- Используются position: sticky, relative и absolute.
- Форма обратной связи с полями, placeholder, фокусом и проверкой HTML5.

Важно о форме
-------------
Форма демонстрирует валидацию на стороне браузера, но не отправляет данные
на сервер. Для реального получения сообщений необходимо подключить backend
или внешний сервис обработки форм. Не вводите настоящие личные данные
в демонстрационную форму.

Как опубликовать на GitHub Pages
--------------------------------
1. Войдите в GitHub и нажмите New repository.
2. Назовите репозиторий, например aura-final-project.
3. Выберите Public и создайте репозиторий.
4. Загрузите index.html, style.css и script.js в корень репозитория
   через Add file -> Upload files, затем нажмите Commit changes.
5. Откройте Settings -> Pages.
6. В разделе Build and deployment выберите Deploy from a branch.
7. Укажите Branch: main и Folder: / (root), затем нажмите Save.
8. Подождите завершения публикации. Адрес обычно будет иметь вид:
   https://ВАШ-ЛОГИН.github.io/aura-final-project/

Если репозиторий называется ВАШ-ЛОГИН.github.io, сайт будет доступен
по адресу https://ВАШ-ЛОГИН.github.io/

Ссылка появится в разделе Settings -> Pages. Её можно отправить
преподавателю после проверки, что сайт открывается.
